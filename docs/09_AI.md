# 09 — AI Platform

## Providers

An injectable, tenant-neutral generator speaks to any **OpenAI-compatible**
base URL. Each tenant may supply their **own API key** (`organization_ai_settings`);
without one, the platform's included AI is used. A `DisconnectedWebsiteGenerator`
fallback keeps the app functional with no key.

## Prompt architecture

Today: task-specific prompts for website generation (business brief → site
HTML). Phase 3 will introduce a structured **AI tool registry** with typed
schemas so the AI Command Center invokes validated tools rather than free-form
actions.

## Tool registry (planned, Phase 3)

Read-only tools (no confirmation): searchClients, searchLeads,
listOverdueInvoices, getClientSummary, getPipelineSummary, getTicketSummary,
getProjectSummary, getRevenueSummary, searchKnowledgeBase. Write tools
(**require explicit confirmation**): createClient, updateLeadStage,
createProposalDraft, createInvoiceDraft, createProject, createTicket, sendEmail,
enrollInSequence, publishWebsite. Every tool enforces permissions +
`TenantContext`; the AI never generates or executes raw SQL.

## AI Employees (planned, Phase 3)

Role-based assistants (Receptionist, Sales, Marketing, Project Manager,
Support, Copywriter, Website Designer, SEO, Publishing, Ministry) configured per
tenant with allowed tools, knowledge collections, approval policy, and usage
limits. Generated/automated activity is always labeled as such; high-risk
actions stay approval-based.

## Knowledge Base

Collections → documents → chunks. v1 retrieval is keyword-based over Postgres
behind a `RetrievalProvider` interface; answers are **grounded** strictly in
retrieved chunks and cite their source documents, returning empty when nothing
matches. Embedding + pgvector retrieval and LLM answer synthesis are planned.
See `08_MODULES.md` (Knowledge Base) and `04_SECURITY.md` (AI safety).

## Embeddings

Not yet generated (v1 is keyword). The interface is embedding-agnostic; a
`PgVectorRetrievalProvider` will embed documents at ingest and queries at ask
time.

## Usage metering

Every AI generation records a usage event (`ai_usage_events`) in micro-dollars;
monthly **plan allowance caps** gate platform-key usage. BYO-key usage runs on
the tenant's own account.

## Safety

- Ground answers in retrieved material; never fabricate.
- (Phase 3) preview + explicit confirmation before any mutation or financial
  action; per-tool permission + tenant enforcement; full audit of request →
  proposed action → confirmation → execution → result; never expose secrets.

## Future AI roadmap

pgvector semantic retrieval; AI Command Center; AI Employees; document
ingestion (PDF/Docx); grounded answer synthesis with inline citations.
